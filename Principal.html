Actores, escenarios y reglas de decisión

Define actores con su tipo (comunidad, privado, estatal), su postura y su poder de negociación. Luego describe reglas cuando / entonces que disparan alertas o acciones automáticamente al simular.

// Ejemplo real del proyecto

escenario PosturasTiticaca {

actor ComunidadLago { tipo = "COMUNIDAD"; postura = 90; poder = 0.6; }

actor EmpresaTuristica { tipo = "PRIVADO"; postura = 20; poder = 0.8; }

}

simular Simulacion_01 {

escenario = PosturasTiticaca;

variable nivel_riesgo = 0;

calcular(nivel_riesgo, conflicto);

cuando (nivel_riesgo > 50) entonces {

alerta("Alto_Conflicto");

}

}

Bloques del lenguaje

Ocho conceptos, un ecosistema completo

Cada palabra clave de CSL representa una pieza real del análisis de conflictos socioambientales.

actor

Una parte del conflicto: comunidad, empresa privada o entidad estatal, con su postura y poder.

escenario

Agrupa a los actores que participan en una situación específica a simular.

negociacion

Partes en diálogo y un umbral de acuerdo necesario para llegar a consenso.

coalicion

Une a varios actores en un bloque con poder combinado.
